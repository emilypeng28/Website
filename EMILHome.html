Name Tag

Description

A name tag where each letter can be customized. This was made for my grade 10 coding final project with the p5.js library.

Interactives

Press "SPACE" to generate a random letter slot combination. CLICK a letter to change its design.

Letter Designs

Index 0: Block letters, cycles through the color wheel Index 1: Round letters, rainbow background Index 2: *Unable to be displayed in browser Index 3: Light bulbs, light up from top to bottom Index 4: Letters in pixel font Index 5: Cloud of pixels that form the shape of the letter Index 6: Shadow font Index 7: E: Neon tube M: Rainbows I: Chimney tube and smoke L: "Barber pole"

Process

Foundation

  • The grid function made for the Fish Simulator is reused to plan out the layout
  • Each letter has its own function for drawing it
  • The function's second parameter dictates its size (the first being its index)
  • A test function is used to draw the letter larger to make designing it easier
  • The code is then copied to its respective letter function

Changing letter designs

  • Detects mouse location when clicked to change the corresponding letter index
  • The index is the first parameter of the letter drawing function (the second being size)
  • A different design is drawn depending on the index
  • This simplifies the process of adding new designs to a letter

Arc Tool

  • I wanted to learn how to use the drawing function arc()
  • Is parameters include the location coordinates, its size coordinates, the start and end angles of the arc, and an optional mode parameter
  • Was used to draw indexs 1, 7E, and 7M
