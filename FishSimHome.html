Fish Room


Description

A small simulator of a fish swimming in a fish tank made with the p5.js library. It was a school project where I took the opportunity to go all out on what I knew at the time.

Interactives

Keys

Press "ENTER" to reset the simulator Press "SPACE" for the fish blow bubbles Press "=" to add an iteration to the Sierpenski Triangle Press "-" to remove an iteration from the Sierpenski Triangle

Mouse

The FISH will follow the mouse around. If FISH FOOD is dropped into the tank, the fish will eat it before resuming to following the mouse. You can also pop the BUBBLES, close the LIGHTS, and click the fish to make it glow when it's dark

Process

Fish

  • The fish and mouse's position coordinates are used to calculate their slope
  • The slope is used to determine what angle the fish should swim
  • Eyes, fins, and tail coordiantes are positioned relative to the fish body
  • The fish's position is contrained to remain inside the tank

Background

  • A grid function was written to use as a guide to drawing the background
  • Rule of thirds is loosly used for the composition
  • Water is constantly slightly changing between different hues of blues to make it look more dynamic

Light Switch

  • A variable stores a boolean value representing the light switch's status
  • The variable changes if the user clicks within the switch's coordinates
  • All elements' color are multiplied by a variable called darkness
  • When lights are off, the darkness variable gives each element a darker value

Food

  • A variable mode is used to indicate how the fish and food should react
  • If the user clicks the food box, a food shape is drawn using an array of randomized values (Mode 1)
  • Once created, the food can be dragged around (Mode 2)
  • When the food is dropped, the fish follows the food until it is eaten or falls off the screen (Mode 3)
  • After the food is no longer visible, the fish and food resets (Mode 0)

Bubbles

  • A 2-dimensional array hold each bubble, and their properties' values
  • A bubble's properties are randomly generated when they form
  • Every refresh, the program goes through each array item to draw each bubble, modifying them when necessary
  • An element value is set to 0 when its bubble pops

Seaweed

  • Like with the bubbles, an array is used to store the information of each seaweed
  • A function is written to create values for each seaweed's starting coordinates
  • Every refresh, each of the nodes' coodinate values are changed slightly
