Snake Game


Description

This is a standard snake game. It was my first project using the p5.js library, and was a personal project made to familiar myself with its functions.

How to Play

  • Press space to start and pause
  • Use arrow keys or AWSD to change the snake's direction
  • Eat apples to grow longer
  • Don't run into yourself or the walls
  • Earn as many points as possible (seen on top left corner)


Process

Creating the Snake

  • Two arrays are used to track the the position of each snake segment among the x and y axis
  • After changing direction, the head's coordinates are rounded accordingly to prevent self-collision
  • When an apple is eaten, new coordinates are appended to make the snake grow

Background

  • Rule of thirds and hierarchy are implemented to grab viewer's attention
  • Pixel art is from https://www.youtube.com/watch?v=fL5bFAgIQeA
